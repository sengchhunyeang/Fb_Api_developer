1របៀបដែលប្រព័ន្ធដំណើរការ

គម្រោង Django ហៅទៅ Facebook Graph API ដោយប្រើ Page Access Token ហើយទាញយកប្រកាសម្តងមួយទំព័រៗ រហូតដល់បានប្រកាសទាំងអស់ បន្ទាប់មកបង្ហាញលើគេហទំព័រ និងជា JSON។

Facebook App→ សិទ្ធិ Page→ User Token→ Token អាយុវែង→ Page Token (មិនផុតកំណត់)→ .env→ Django UI / API

អ្វីដែលអ្នកត្រូវការ

  • គណនី Facebook ដែលមានសិទ្ធិ Facebook access with full control លើ Page។
  • Python 3.12 ឬថ្មីជាងនេះ នៅលើកុំព្យូទ័ររបស់អ្នក។
  • ថតគម្រោង៖ D:\s.chhunyeang\Personal\Webs\fb-posts

2បង្កើត Facebook App

  1. ចូលទៅ developers.facebook.com/apps ហើយ Log in។
  2. ចុច Create App វាយឈ្មោះ App រួចចុច Next។
  3. នៅក្នុងបញ្ជី Use case (All) ធីកតែមួយគត់ Manage everything on your Page រួចចុច Next។
  4. ផ្នែក Business portfolio៖ ជ្រើស I don't want to connect a business portfolio yet → Next។
  5. ចុច Next រហូតដល់ចប់ → Create app (បញ្ចូលពាក្យសម្ងាត់ ប្រសិនបើវាសួរ)។

សំខាន់៖ Use case ត្រូវតែជា Manage everything on your Page។ App ដែលគ្មាន Use case សម្រាប់ Page មិនអាចយកសិទ្ធិ Page បានទេ — Token នឹងមានតែ public_profile ប៉ុណ្ណោះ។

3បន្ថែមសិទ្ធិ Page ទៅក្នុង App

  1. បើក App របស់អ្នកពី developers.facebook.com/apps។
  2. នៅម៉ឺនុយខាងឆ្វេង ចុច Use cases។
  3. នៅលើកាត Manage everything on your Page ចុច Customize (ឬប៊ូតុង ✏️ / Edit)។
  4. នៅក្នុងបញ្ជីសិទ្ធិ ចុច Add នៅជាប់នឹង៖
    • pages_show_list
    • pages_read_engagement
    • pages_read_user_content
  5. សិទ្ធិនីមួយៗគួរបង្ហាញ Ready for testing។ ចុច Save ប្រសិនបើមាន។

គន្លឹះ៖ ចុច Ctrl + F ដើម្បីស្វែងរកសិទ្ធិក្នុងបញ្ជីវែង។ មិនចាំបាច់ App Review ទេ ព្រោះអ្នកជា Admin របស់ App និង Page។

4យក User Token (Graph API Explorer)

  1. បើក Graph API Explorer ហើយ Refresh ទំព័រ (F5)។
  2. នៅខាងស្តាំ ត្រង់ Meta App៖ ជ្រើសរើស App របស់អ្នក។
  3. ត្រង់ User or Page៖ ជ្រើស Get User Access Token។
  4. ចុច Add a Permission៖ បន្ថែមសិទ្ធិ pages_... ទាំង ៣ ដដែល។ លុបសិទ្ធិ user_... ចេញ។
  5. ចុច Generate Access Token។
  6. នៅក្នុងផ្ទាំង Popup ចុច Edit previous settings (ប្រសិនបើមាន) ធីក Page របស់អ្នក រួចចុច Continue → Save។
  7. ចម្លង Token ពីប្រអប់ Access Token (ចាប់ផ្តើមដោយ EAA…)។

Token នេះផុតកំណត់ក្នុងរយៈពេលប្រហែល ១ ម៉ោង។ ជំហានបន្ទាប់នឹងប្តូរវាទៅជា Page Token ដែលមិនផុតកំណត់។

5ស្វែងរក Page ID

វិធី ក — នៅលើ Facebook៖ បើក Page របស់អ្នក → About → Page transparency → Page ID។

វិធី ខ — នៅក្នុង Graph API Explorer៖ វាយឈ្មោះ Username របស់ Page រួចចុច Submit៖

cdlsolutionskh?fields=id,name

លទ្ធផល៖

{ "id": "100604454959362", "name": "CDL Solutions" }

6ពន្យារអាយុ Token

  1. បើក Access Token Debugger។
  2. បិទភ្ជាប់ User Token ពីជំហានទី ៤ ហើយចុច Debug។
  3. ពិនិត្យ៖ Type: User, Valid: True និងមានសិទ្ធិ pages_... ទាំង ៣។
  4. រំកិលចុះក្រោមបំផុត ហើយចុច Extend Access Token។
  5. ចម្លង អត្ថបទ Token ថ្មី ដែលបង្ហាញនៅក្រោមប៊ូតុង (ចាប់ផ្តើមដោយ EAA…)។ ពេល Debug វា គួរបង្ហាញ Expires: in about 2 months។

ត្រូវចម្លង អត្ថបទ Token មិនមែនតារាងព័ត៌មាន (Issued / Expires / Scopes) ទេ។ តារាងព័ត៌មានមិនមែនជា Token ទេ។

7យក Page Token អចិន្ត្រៃយ៍

  1. ត្រឡប់ទៅ Graph API Explorer វិញ។
  2. បិទភ្ជាប់ Token អាយុវែង ពីជំហានទី ៦ ចូលក្នុងប្រអប់ Access Token។
  3. វាយសំណើនេះ (ប្រើ Page ID របស់អ្នក) ហើយចុច Submit៖ 
    100604454959362?fields=name,access_token
  4. ចម្លងតម្លៃ access_token ពីលទ្ធផល — នេះគឺជា Page Token។
  5. ពិនិត្យវានៅក្នុង Access Token Debugger៖ Type: Page, Expires: Never។

Page Token ដែលបង្កើតចេញពី User Token អាយុវែង មិនផុតកំណត់ទេ។ មានតែ Data Access ប៉ុណ្ណោះដែលត្រូវបន្តរៀងរាល់ ៩០ ថ្ងៃម្តង — ការប្រើប្រាស់ធម្មតានឹងបន្តវាដោយស្វ័យប្រវត្តិ។

12សុវត្ថិភាព

  • Page Token និង App Secret គឺដូចពាក្យសម្ងាត់ — កុំចែករំលែកក្នុង Chat, Email ឬរូបថតអេក្រង់ ហើយកុំ Commit .env។
  • ប្រសិនបើ Secret ត្រូវបានចែករំលែករួចហើយ សូម Reset វា៖ App → App settings → Basic → App secret → Reset។
  • UI និង API មិនទាន់មានការ Log in ទេ។ សូមបន្ថែមការផ្ទៀងផ្ទាត់អត្តសញ្ញាណ មុនពេលដាក់គេហទំព័រឱ្យដំណើរការលើអ៊ីនធឺណិត។
  • មុនពេល Deploy៖ កំណត់ DEBUG = False, កំណត់ ALLOWED_HOSTS និងប្រើ SECRET_KEY ថ្មី។
